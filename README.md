## ▶️ Como Compilar e Executar

### C++

```bash
# Compilar
g++ -o solucao 1001.cpp

# Executar
./solucao
```

### C

```bash
# Compilar
gcc -o solucao 1001.c

# Executar
./solucao
```

> 💡 No Windows, use `.\solucao.exe` para executar.
